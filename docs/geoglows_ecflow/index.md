# GEOGLOWS ECFLOW

The **geoglows_ecflow** package provides an easy way to create a GEOGLOWS RAPID forecast ecFlow job, submit the job to an ecFlow server, and run the job.

For instructions on how to install the package, see [Installation](installation.md).

For a guide on running `geoglows_ecflow` locally and setting up the configuration files, see [Running GEOGLOWS ecFlow Locally](running_geoglows_ecflow_locally.md).

If you are new to ecFlow, you may want to read the [ecFlow Overview](ecflow.md) page to get an overview of the ecFlow concepts that the `geoglows_ecflow` package uses.

[GEOGLOWS Forecast Job](geoglows_forecast_job.md) covers the functions and classes that the `geoglows_ecflow` package provides for creating the GEOGLOWS RAPID forecast job.

[Client](client.md) covers the functions that can be used to communicate with and submit jobs to the ecFlow server.

[Utils](utils.md) covers the utility functions that the `geoglows_ecflow` package uses.

The [Resources](resources/index.md) module holds the scripts that are run as tasks in the GEOGLOWS RAPID forecast job.
