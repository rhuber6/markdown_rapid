Installation
============

Regular Installation
--------------------

Run the following commands in your terminal

::

    git clone https://github.com/geoglows/geoglows_ecflow.git
    cd geoglows_ecflow
    pip install .

Development Installation
------------------------

Run the following commands in your terminal

::

    git clone https://github.com/geoglows/geoglows_ecflow.git
    cd geoglows_ecflow
    pip install -e .

Non-Python Dependencies
-----------------------

* rapid>=20210423
* ecflow>=5.11.3
* nco>=5.1.8
* ksh>=2020.0.0
